# Ethereum Basics

Ethereum is a programmable blockchain. Instead of only moving value, Ethereum can run smart contracts: code that lives on-chain and executes according to predefined rules.

Key ideas:
- ETH is the native asset used to pay for transactions.
- Smart contracts power apps such as DeFi protocols, NFT marketplaces, and DAOs.
- Validators secure Ethereum using proof of stake.
- Users pay gas fees when interacting with the network.

Ethereum is useful to study because it introduced a large ecosystem of decentralized applications.
